#завдання із зірочкою

Якщо виконати код lifecycleScope.launch {
    launch(ceh) { // Передаємо обробник сюди
        throw RuntimeException("Вкладений краш!")
    }
}
Що відбудеться і чому:
Застосунок упаде з crash, а повідомлення з ceh не з'явиться
дочірня корутина не обробляє винятки самостійно, якщо вона створена через звичайний launch всередині батьківської корутини
